# To-Do List 📝

A simple command-line To-Do List application built using Python.  
It allows users to add, view, complete, and delete tasks. Tasks are stored in a JSON file so they remain available even after the program is closed.

## Features

- Add new tasks
- View all tasks
- Mark tasks as completed
- Delete tasks
- Save tasks automatically
- Load previously saved tasks
- Simple command-line interface
- Basic input validation

## Technologies Used

- Python
- JSON
- File Handling
